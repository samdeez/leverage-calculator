## 2025-02-18 - Integrating semantic labels with react-number-format
**Learning:** `react-number-format` (`<NumericFormat>`) correctly passes standard HTML attributes (like `id`) down to the underlying `<input>` element. This is crucial for accessibility, as it means we can easily pair `<label htmlFor="...">` with these components without needing complex workarounds or custom wrappers. The previous implementation used `<div className="inputLabel">` instead of semantic `<label>` tags, making it inaccessible to screen readers.
**Action:** When using third-party input components, always verify if they support standard DOM attributes like `id`. If they do, always use semantic `<label htmlFor="id">` instead of visual `<div>` labels to ensure proper screen reader support and form navigation.
