## 2024-05-24 - Missing Semantic Labels for Custom Input Components
**Learning:** In this application, `<NumericFormat>` components (from `react-number-format`) were paired with visually styled `<div className="inputLabel">` tags rather than semantic HTML `<label>` elements. This pattern creates a significant accessibility barrier because screen readers cannot programmatically associate the text description with the corresponding input field, making it difficult for non-visual users to understand what data is required.
**Action:** When auditing forms, specifically search for custom input components (like those from `react-number-format`) and verify they are accompanied by actual `<label>` tags with a proper `htmlFor` attribute that exactly matches an `id` passed to the custom component.
